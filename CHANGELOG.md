# Changelog

## 1.0.0 (2026-10-12)

First release.

- Workout logger: per-set weight/reps, previous-session column, copy last, swap to alternative, rest timer, PR detection
- Routines with alternatives, weekly schedule, three starter templates
- Exercise library of 876 exercises with looping start/finish photos and instructions; custom exercises; slang-aware search
- Body log with targets, 7-day average and straight-line goal tracking
- Progress: weight chart, weekly check, strength (e1RM) chart, history
- Multi-user with admin, invite codes, sign-up modes, password reset
- JSON export/import (merge or replace), portable between servers
- Offline-tolerant saving and installable PWA
- SQLite or PostgreSQL (Supabase-ready), Alembic migrations, Docker image, CI
